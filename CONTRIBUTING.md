# Build the Entity, Earn Alpha Points

This is not a static repository. It is a living organism. To incentivize its growth, we use a decentralized point system.

## How to earn points:
- **Fix a Bug (100 AP):** Submit a PR fixing an issue in `VISUAL/` or `CORE/`.
- **Add a Language (200 AP):** Translate the Entity's dialogue into a new language.
- **Optimize (300 AP):** Improve the Three.js render performance.

Your points are tracked by the Alpha Bot via GitHub Actions.
